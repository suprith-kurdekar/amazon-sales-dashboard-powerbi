# 📊 Amazon Sales Dashboard | Power BI

## 📌 Project Overview
This project is an interactive Amazon Sales Dashboard developed in Microsoft Power BI to analyze sales performance, orders, quantity, average order value, and category-wise insights. The dashboard provides a clean, professional, and interactive view of business performance.

---

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Microsoft Excel
  
---

## 📈 Key KPIs
- 💰 Total Sales
- 🛒 Total Orders
- 📦 Total Quantity
- 💵 Average Order Value
- 🏷️ Total Categories

---

## 📊 Dashboard Features
- Sales by Category
- Sales by State
- Monthly Sales Trend
- Order Status Analysis
- Average Order Value by Category
- Sales by Ship City
- Sales by Style
- Interactive Dashboard Design
